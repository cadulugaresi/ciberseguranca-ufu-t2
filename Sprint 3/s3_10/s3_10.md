## 1. Classificação de sistemas lineares

### Sistema SPD
Sistema:
```text
x + 2y = 7
3x - y = 7
```

Código em NumPy:
```python
import numpy as np

A = np.array([[1, 2],
              [3, -1]])
b = np.array([7, 7])

x = np.linalg.solve(A, b)
```

Resultado:
- det(A) = -7
- Sistema: SPD
- Solução: x = [3, 2]

Verificação:
- 1·3 + 2·2 = 7
- 3·3 - 1·2 = 7

Logo, o sistema possui uma única solução.

### Sistema SPI
Sistema:
```text
x + y = 3
2x + 2y = 6
```

Resultado:
- det(A) = 0
- Sistema: SPI
- A segunda equação é múltipla da primeira.
- As retas coincidem, então há infinitas soluções.

### Sistema SI
Sistema:
```text
x + y = 3
x + y = 5
```

Resultado:
- det(A) = 0
- Sistema: SI
- Os coeficientes são iguais, mas os termos independentes são diferentes.
- As retas são paralelas, então não há solução.

### Interpretação geométrica
- SPD: duas retas se cruzam em um único ponto
- SPI: duas retas coincidem
- SI: duas retas são paralelas

## 2. Modelagem do risco efetivo

O modelo utilizado foi:
```text
x = b + Ax
```
Equivalentemente:
```text
(I - A)x = b
```

Dados:
```python
b = np.array([23.0, 15.8, 17.0])

A = np.array([
    [0,   0.5, 0  ],
    [0,   0,   0.2],
    [0,   0,   0  ]
])
```

Matriz:
```python
I = np.eye(3)
I_menos_A = I - A
```

Resultado:
```python
[[ 1.  -0.5  0. ]
 [ 0.   1.  -0.2]
 [ 0.   0.   1. ]]
```

Determinante:
- det(I - A) = 1
- Como o determinante é diferente de zero, a matriz é invertível e o sistema tem solução única.

Resolvendo:
```python
x = np.linalg.solve(I_menos_A, b)
```

Resultado:
```python
x = [32.6, 19.2, 17.0]
```

Ou seja:
- Notebook: 32.6
- Servidor: 19.2
- Roteador: 17.0

### Cálculo manual
```text
x_R = 17.0
x_S = 15.8 + 0.2 * 17.0 = 19.2
x_N = 23.0 + 0.5 * 19.2 = 32.6
```

Os valores confirmam o resultado obtido por `np.linalg.solve`.

## 3. Conclusão

O modelo de risco efetivo mostra que o risco herdado aumenta o risco próprio de cada equipamento. O Roteador não depende de nenhum outro, logo seu risco efetivo é igual ao próprio. O Servidor herda 20% do Roteador e o Notebook herda 50% do Servidor. Como cada linha de A soma menos que 1, a matriz (I - A) é invertível e o sistema possui solução única.
